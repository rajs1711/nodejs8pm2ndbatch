#MongoDB is a NoSQL(Not Only Sql) database 
designed to store, query, and manage large volumes of 
unstructured or semi-structured data.

Here’s a clear breakdown:

🧠 Basic Concept

Unlike  relational databases (SQL) that use tables, rows, and columns, 
MongoDB stores data in collections made up of documents.

Each document is stored in a JSON-like format called BSON (Binary JSON) — which allows for flexible, nested data structures.

📦 Example

A document in MongoDB might look like this:

{
  "_id": 1,
  "name": "Alice",
  "age": 30,
  "skills": ["Python", "MongoDB", "Node.js"],
  "address": { "city": "London", "zip": "SW1A 1AA" }
}


This is much more flexible than a traditional table, since each document in the same collection can have different fields.

⚙️ Key Features

Schema-less: You don’t need to define a rigid schema beforehand.

Scalable: Built for horizontal scaling using sharding (spreading data across multiple servers).

High performance: Supports fast reads and writes.

Powerful query language: Supports rich queries, aggregations, and indexing.

===========================  Aggregation PIPELINE ===================
  * GroupBY  * avg,sum,max,min,sum * pipeline ,* stage
=====================================================================
 WAQ to find out total number of resturants in each location .

Notes: to implement group we have to use Aggregation pipline .
    
       An aggregation pipleine is consist of one or more that one stages that process documents.
         each stage performs an operation on the input documents  and which is the output for next stage .
    An aggregation pipeline can return results of groups of document  for Exampl
    total count , sum , average . or we can perform joins between collections.

syntex:

db. collectionname.aggregate([
    {<stage 1>},
    {<stage 2>},
    {<stage 3>}
]);

1. WAQ to find out total number of students in each department .




db.students.aggregate(
[

   {
   
     $group:{
     
         _id:"$address",
         totalcount:{$sum:1}
     }
   }

]

);

2. WAQ to find out total number of students in each department order by student count desc.


db.students.aggregate(
[

   {
   
     $group:{
     
         _id:"$address",
         totalcount:{$sum:1}
     }
   },
   
   {
   
    $sort:{totalcount:-1}
   }

]

);

2. WAQ to find out total number of students in each department order by student count desc limit 2



db.students.aggregate(
[

   {                                                      // stage 1
   
     $group:{
     
         _id:"$address",
         totalcount:{$sum:1}                               
     }
   },
   
   {                                                     //  stage 2
   
    $sort:{totalcount:-1}
   },
   
   {                                                     //  stage 3
   
   $limit:2
   
   }

]

);
